# Contributing to mute-gadget-sdk

Pull requests are welcome.

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Make sure the test suites pass (see each directory's `README.md`).

Report bugs in GitHub issues. Report security problems privately through
GitHub's security advisories for this repository, not in a public issue.

By contributing, you agree that your contributions are licensed under the
[`LICENSE`](LICENSE) file in the root of this repository.
