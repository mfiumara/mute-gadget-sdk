# Community Device Skills

Community-sourced skills for using devices with Mute Gadgets. These are not official integrations.

To try one, give your mute a link to this GitHub repo in its chat and let it find the skills it needs.
Alternatively, find your device in the [catalog](CATALOG.md), then copy and paste its `SKILL.md` into your mute's chat. Include any shared skills it references, such as Google Cast.

Contributors are welcome to submit PRs for devices they've found work with Home Link. Use a `gadget-<device-name>/SKILL.md` with a matching YAML `name`, a `description`, instructions, limits, and source links. Keep skills Markdown-only.

These skills may eventually be made available in the Mute product.
